## 画面の流れ

- 開始ページ：教材名＋Lesson番号、「はつおんのれんしゅうをしましょう。」、スタート。
- Talk：開始 → お手本動画 → 質問を話す → 声を聞き直す → 応答を話す → 声を聞き直す → 結果。
- About myself：開始 → チャレンジ動画 → 8・11・13秒で停止し、それぞれ発話と聞き直し → 動画の残り → 結果。
- 進行中のロゴ・教材名・Lesson番号は、コンパクトなヘッダーの1か所のみ。
- 手順イラストは開始ページだけに表示。発話画面では操作ボタンに同じタッチのイラストを利用。
- 「やりかた」「つかいかた」ボタン、ヘルプ画面、操作説明音声はありません。

## 星の結果

できた場合は星3つ、もう一度の場合は星1つのリボン表示を用意しています。

現時点では音声認識・判定APIは未接続です。録音内容から星の数を判定することはなく、表示される星はすべて「評価サンプル」です。録音モードでは、録音・自分の声の再生が実際に動きます。録音後はお手本と自分の声を同じ画面で聞き比べられます。

「画面確認」を開くと、星3つ・星1つを切り替えて表示でき、動画をスキップできます。子ども向けの説明機能ではなく、モックの確認用操作です。

API接続時に、判定結果を3つ星または1つ星へ対応させる処理を追加します。

## 録音と対応環境

最大30秒。音声はページ内のメモリだけで扱い、外部送信しません。録音終了・キャンセル・ページ終了時にマイクを解放し、次の問題や再録音で以前の録音を破棄します。

Mac上のChromeに合成テスト音声を入力し、録音・再生・画面遷移・3つ星／1つ星の表示を確認済みです。iPad Safari、Windows、Androidの実機検証は未実施です。

## 画面確認モードと録音モード

初期状態は「画面確認モード」です。「はなす → おわった → 星の結果」をマイクなしで確認できます。このモードでの「再生サンプル」はお手本音声を使い、自分の声と区別しています。

実際に録音する場合は、下部「画面確認」を開き「実際にマイクで録音する」にチェックを入れてください。録音後に「じぶんのこえ」を再生できます。

マイクの許可が拒否された場合や許可待ちの場合も、「マイクなしで画面確認」で結果まで進めます。

教材名の表示は、両方で共通の笑顔のキャラクターと淡い背景を使い、サイズを増やさず親しみやすくしています。Talkは緑と吹き出し、About myselfはピンクと手を振る仕草で区別します。

## 繰り返し練習

録音モードでは「じぶんのこえ」を聞いたあと「もういちど はなす」で、同じ問題を何度でも録り直せます。新しい録音と直前の録音の2つを保持し、聞き比べできます。短すぎる録音や録音失敗では、以前の録音を消しません。

前々回より古い録音は、新しい録音の成功時に破棄します。次の問題・終了・モード変更時には、保持している録音をすべて破棄します。音声はサーバーに送信しません。
