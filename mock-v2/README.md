# 第2案：本番向け画面

第1案とは別の、元教材に近い画面遷移で動くHTML教材です。

## ファイル

- `public/talk-v2.html`
- `public/aboutmyself-v2.html`

それぞれ動画・音声・画像・ロゴ・CSS・JavaScriptを含む独立HTMLです。録音する場合はHTTPSまたはlocalhostで開いてください。

## 画面と操作

- 開始ページ：教材名とLesson番号、「はつおんのれんしゅうをしましょう。」、スタート。
- 進行中のヘッダーにロゴ・教材名・Lesson番号を1回だけ表示。
- Talk：お手本動画 → 質問の発話と聞き直し → 応答の発話と聞き直し → 結果。
- About myself：動画が8・11・13秒で止まり、発話と聞き直し → 動画の残り → 結果。
- 「はなす」で録音を開始し、「おわった」で停止。「じぶんのこえ」で録音を再生します。
- お手本と自分の声を交互に聞き比べできます。
- 同じ問題で「もういちど はなす」を何度でも使えます。新しい録音と直前の録音を保持します。
- 短すぎる録音や失敗した録音では、前の有効な録音を消しません。
- 「再生サンプル」「画面確認」などの確認用UI、録音モードの切替、ヘルプは表示しません。
- Talkは緑、About myselfはピンク。同じタッチの笑顔のキャラクターで区別します。

## 判定の実装状況

音声認識・発音評価APIは未接続です。録音・聞き直し・録り直しは実際に動きますが、発音は採点していません。

未判定の録音に仮の星を付けることはありません。現状は星を中立表示にし、録音の聞き直しを促します。結果画面も、実際に判定していない星を表示しません。

API接続後、判定結果を「できたら星3つ／もう一度なら星1つ」に対応させます。無音やマイク・通信の不具合を発音の失敗として扱わない設計です。

## 音声の扱い

録音は1回最大30秒。音声はページのメモリ内のみで扱い、外部送信しません。録音終了・キャンセル・ページ終了時にマイクを解放します。

新しい録音の成功時に前々回以前を破棄し、次の問題や終了時には保持している音声をすべて破棄します。録音はリロード後には残りません。

マイクが拒否された場合はエラーを案内し、録音や判定ができたような画面には進みません。

## 確認

Mac Chrome上で合成テスト音声を使い、録音・再生・録り直し・直前との比較・失敗時の保持・音声データ解放を確認しています。iPad Safari、Windows、Android実機での確認は別途必要です。
